# Station Zero kit lists

Package TF7 of the Station Zero build plan: for each of the 19 zones, the stock models, materials and effects
of the five shipped zombies maps (zmb, disco, town, final, rave) that fit its look, with sizes and where the shipped maps use them,
and the objects no stock model fits (GAPS, models to author). Generated by `tools-source/iwzmap/scenes/kit_lists.py`
from the hand-written `station_zero_kit_select.json`; the data is `station_zero_kits.json`.

Regenerate: `python -I tools-source/iwzmap/scenes/kit_lists.py --catalog <catalog.json> --ported-catalog <catalog_bo3_converted.json> --smodels-csv <stock-smodels.csv> --sqlite <cp_zmb.sqlite> --fx-csv <zone>=<zone csv> ... --out-md docs/STATION-ZERO-KITS.md`; it exits 1 when a name is missing.

Nothing here is placed or seen in the game: a name in a table means it exists in a dump and was chosen by
its name, category and size, not that it looks right in the station. Sizes are the model bounds in game units
(x by y by z, catalogue bounds). "Uses in Spaceland" is the number of static instances in the shipped map
(cp_zmb). "Donor" is yes when the model appears among the static models compiled in the template map cp_zmb,
which a generated map can reuse as a static model; a model without a donor counts as an entity until a later
package proves otherwise. "Zones" lists where the model ships (zmb, disco, town, final, rave).
