# Creation tools on the main line

Every tool below lives under `tools-source/iwzmap/` and is on `main`. Paths are
relative to the repository root. Commands run from `tools-source/iwzmap` unless
the test command says otherwise. The map generator is built for the zombies
usermap "Station Zero" but the tools are written to serve any generated IW7
zombies usermap. Read `tools-source/iwzmap/README.md` first for the build chain.

"Proven in the running game" is copied from the documents of each area, never
guessed. "Not recorded" means the area's documents describe the tool but give no
result from a running game. An undated result is marked as such.

## What every map maker should know

- The offline gates (emit, zone, volume, plan, nav connectivity) are the first stop; the checks registered in
  `checks.json` run them on every change of the tools.
- Anything meant to leave the lab depends on the darkness and bake chain being built with the ZoneTool branches named
  in the READMEs; the build scripts in `tools-source/iwzmap` still carry the machine paths of the original runs.
